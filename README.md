## Featured Project

### French Pronunciation Lab

[Live website](https://french-pronunciation-lab.shaotianxiao1013.chatgpt.site) · [GitHub repository](https://github.com/Songtaoxian/french-pronunciation-lab)

An interactive French learning website for Chinese-speaking learners, focused on the pain points of French spelling and pronunciation memory.

Core features:

- listening dictation
- pronunciation prediction with IPA
- phoneme-letter mapping
- high-frequency spelling rule practice
- French special-character soft keyboard
- mistake book and spaced review
- word roots and word-family associations
- verb conjugation practice
- mastery tracking
- leveled vocabulary browser for A1 / A2 / B1 / B2

The vocabulary architecture is designed for open, large-scale French lexical data such as Lexique, Wiktionary dumps, open pronunciation/audio indexes, and frequency datasets, rather than copying copyrighted commercial dictionaries.
